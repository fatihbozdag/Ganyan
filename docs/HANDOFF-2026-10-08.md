## Steps for the local agent (ask the operator before each)

1. **Get the branch:** `git fetch origin audit-2026-09-18-repairs-ie4xic &&
   git checkout audit-2026-09-18-repairs-ie4xic`. Check `.git/info/exclude`
   (block dated 2026-10-03) still hides local-only paths; do not commit
   models/, logs/*.py, GanyanGUI/ or .env.
2. **Install + migrate:** `uv sync --all-extras`, `uv run ganyan db init`,
   then `uv run pytest tests/ -q` (expect 329 passed, 1 skipped).
3. **Repair stored results:** back up the DB first
   (`pg_dump ganyan > ~/ganyan-backup-$(date +%F).sql`), then
   `RESULTS_ONLY=1 scripts/rebuild_scrape.sh <earliest race date> <today>`
   (~6 min/month, resumable). Then
   `UPDATE race_entries SET scratched = true WHERE finish_time = 'Koşmaz'
   AND coalesce(finish_position, 0) = 0;` and verify weight coverage:
   `SELECT avg((weight_kg IS NULL)::int) FROM race_entries WHERE NOT scratched;`
4. **Live data collection:** keep exactly one scheduler enabled (unset
   `GANYAN_SKIP_SCHEDULER` in one process); confirm `agf_snapshots` and
   `external_signals` grow daily. This is the data any future edge test needs.
5. **Production model:** do not overwrite live files. The live ranker has
   no recorded training window, so `model-gate` refuses it as baseline;
   replacing it is an operator decision, not something to route around.
6. **Open a PR** from this branch to `main` when the operator agrees.
